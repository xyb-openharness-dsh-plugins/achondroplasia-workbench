## 二、非肿瘤语义替换表（1.3 号规则落本病种）

| 不能搬（肿瘤/血液语义） | 换成（软骨发育不全语义） |
| --- | --- |
| D+N 天数、day_index、疗程编号折叠 | 年龄「X 岁 X 月」+ 距上次测量 N 天 + 近 12 月测量次数 |
| 阶段标签（术后/巩固/维持） | 一次手术 / 一次调药 / 一次筛查随访 作为折叠单元 |
| 疗效、预后、fit 评分、MRD 转阴 | 只列医生原文与日期；生长百分位只并列官方曲线参考值，不判定 |
| 指标卡下降级箭头 | 「较上次」或「近 12 月中位数」，不暗示好坏 |
| 肿瘤标志物趋势话术 | 身高/体重/头围（按 ACH 专用曲线口径标注「不可比」），听力/睡眠等检查结果原文 |
| 「你已进入 Z 期」急性提醒 | 只用医生已确认的行动计划原话；筛查提醒写「下次随访可问医生是否需要」 |

## 三、与已开工 38 仓的差异化（防换名复用，M1 全量化）
