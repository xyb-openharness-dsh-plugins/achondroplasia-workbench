## 二、非肿瘤语义替换表（本台 R3 落法）

| 不能搬 | 换成 |
| --- | --- |
| D+N 天数、day_index、疗程编号折叠 | 年龄「X 岁 X 月」+ 距上次测量 N 天 + 近 12 月测量次数 |
| 阶段标签（术后/巩固/维持） | 一次手术 / 一次调药 / 一次筛查随访 作为折叠单元 |
| 疗效、预后、MRD 转阴 | 只列医生原文与日期；生长值只并列 ACH 曲线参考区间（【待核】），不判定 |
| 指标卡下降级箭头 | 「较上次」或「近 12 月中位数」，不暗示好坏 |
| 肿瘤标志物趋势话术 | 身高/体重/头围（Hoover-Fong 2022 曲线口径，标注「不可比」）、听力/睡眠结果原文 |
| 小时级轨道事件类型 | 测量 / 筛查 / 就诊 / 手术 / 注射 / 缓解开始→改「事件发生」 |
| 「你已进入 Z 期」 | 只用医生已确认的行动计划原话；筛查提醒写「下次随访可问医生」 |

## 三、与已开工仓的差异化矩阵（5 条全量）

## 四、重名率实测（M1，2026-11-05）

- 方法：计划一级导航（看板/生长记录/筛查台账/事件档案/就诊准备/临床试验/设置）与两基准一级导航原文逐词比对。
- 小粉宝（app.js:33-37）：看板、病情整理、病情一图秀、临床、营养支持、心理支持、全程与康复、收藏与回顾。
- 小橙宝（app.js:57-62）：看板、诊断与基因、诱导与疗程、粒缺血象与支持、MRD 与随访、移植、病情一图秀、营养与生活、心理与家庭、临床研究、资料与复诊。
- 字面全字重合：1/7（看板）= **14% ≤ 70% 达标**。差异化点：「就诊准备」在两基准均为二级页，本台升一级（R3 家长高频任务）；「生长记录/筛查台账/事件档案」为 R3 特有。
- M2 复测：用实际 DOM 导航文本再测一次，更新本节。
