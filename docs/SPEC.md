# SPEC · 小苗宝 GrowPal（软骨发育不全患儿家庭工作台）项目规格

版本：v0.3（M1 全量：调研落定，G1 决策点见 docs/signoffs/G1-自动签认.md）· 状态：草案（0 访谈、0 临床审核，如实标注）
继承：DEV-REQUIREMENTS（需求）、SCENARIOS（场景）、INTERACTION-DESIGN（IP 路径）、CLINICAL-DATA（医学边界）、DIFF-MATRIX（差异化）。

## 问题、用户与最小闭环

- 输入：家长手里的生长测量值、筛查报告、手术与用药记录、医生原话。
- 动作：录入/导入→核对候选→建档→回看轨迹→生成就诊资料包。
- 输出：可追溯的随访档案 + 复诊资料包 + 待问清单。
- 失败恢复：录错走更正=新版本；缺资料如实显示未记录。
- 成功标准：S1–S8 八条一期场景各有一条 IP 路径走通并留可观察产物。

## 方案与 ADR

- 方案选择：沿用家族 business-first 布局（中间业务主区 + 右侧 AI 面板），R3 形态叠加「家长代记/本人」双视角徽标与更严隐私默认。备选（左侧 AI、浮动面板）因家族一致性淘汰。
- 数据边界：ARCHIVE/METRIC/EVENT/SCREENING/REPORT 等通用表 + 本病种生长与筛查专属表（M3 定稿）；无 diagnosis/risk_level 判定列；百分位对照值读时算不入库。

## 功能范围（一期，对应 DEV-REQUIREMENTS R1–R6）

- 看板：今日概况（最新生长值、下次随访待查项、私密条数提示）+ 快捷卡三连。
- 生长记录：一图秀（身高/体重/头围分线，ACH 曲线对照口径「不可比」）+ 指标卡（真 3D 翻转）+ 录入/更正。
- 筛查台账：分类区块（听力/睡眠/影像/骨科）+ 眉题 + 登记窗口 + 随访节律清单。
- 事件档案：手术/调药折叠卡（details.phase-fold）+ 医生原话分列 + 更正链。
- 就诊准备：资料包预览 + 导出（私密过滤）+ 待问清单。
- 临床试验：登记快照 + 候选线索（无匹配指数）；CTG 实测 47 项（2026-11-05）；在线通道失败则如实降级空态。
- 疾病概要：? 整页四段（定义/规范与指南/治疗全景/趋势），逐条来源+固定免责两句。
- 设置：工作区 / 文档解析（MinerU 未接入如实标注）/ 临床数据库 三 Tab。

## 数据与 API

- 两套合成档案 A/B 为唯一演示源；页面不写死数字；切换整页联动。
- 排序 ORDER BY rowid；显式 null；in_use；分节 *_title；分类不进趋势。

## 验收

M2 检查点清单逐条报数（IP/X/C/MT/A/P/Q）；M5 check 链全绿；M6 真机走查（不可用如实记）。
