## 三、痛点假设（待访谈核实，不冒充引语）

1. 生长记录散落，复查时讲不清轨迹。
2. 筛查项目多（听力/睡眠/颅颈/脊柱/下肢），记不住哪些查过、下次查什么。
3. 每日注射类药物的依从记录容易漏。
4. 遗传与再生育信息来源混乱，网上说法与医生说法分不清。
5. 儿童数据被他人看到/误用的担忧高于成人病种。
