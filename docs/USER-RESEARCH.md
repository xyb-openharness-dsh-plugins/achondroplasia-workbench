## 四、对一期功能的修正

1. 「复诊与取药强绑定」超出原假设（只想到复诊）——就诊准备页保留「取药安排」字段（自由文本，不提醒用药）。
2. 注射记录不叫「打卡」（打卡暗示依从评判），叫「注射记录」，孩子配合度只自由文本。
3. 筛查台账所有频次不引用数字，列表项来自医生安排或家长手填。
