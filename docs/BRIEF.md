# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：软骨发育不全患儿及家长照护者（代记主体为家长）；含新生儿期确诊至青春期随访的家庭；骨科/儿科/遗传科随访场景；病友组织志愿者协作使用

场景：患儿生长档案（身高体重头围逐次测量，按官方生长曲线口径对照、不判读）；年度并发症筛查节奏与结果（颅颈交界狭窄/阻塞性睡眠呼吸暂停/中耳炎与听力/脊柱后凸/下肢弓形，阈值【待核】）；手术记录与用药事件（伏索利肽等按日注射记录，医生原话分列）；就诊资料包与待问清单；家长代记双视角与更严格隐私默认

核心流程：
1. 选择本机资料目录并导入生长测量/听力/睡眠/影像检查报告
2. 核对候选信息，建立患儿生长档案与随访档案
3. 记录生长指标、筛查结果与手术用药事件
4. 整理年度随访节律与下次就诊待查项
5. 生成复诊准备材料与家长代记标记的记录

完成结果：得到来源可追溯、可核对的患儿随访档案：生长记录轨迹、并发症筛查节奏与结果、手术与用药事件、复诊准备材料；所有候选信息经家长核对入档，不提供诊断与治疗建议，不输出生长达标/落后判定

初始布局选择：business-first
