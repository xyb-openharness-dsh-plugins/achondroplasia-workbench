# INTERACTION-DESIGN · 交互路径（IP）与状态设计（小苗宝 GrowPal）

版本：v1.0（M1 全量，28 号 IP1 落地）· 文档版本号与本台原型一致：IP 文档 v0.1，原型 v0.2。

## 一、一级导航（R3 形态定稿版；重名率实测 14% 见 DIFF-MATRIX §四）

1. 看板（今日概况：生长最新值、下次随访、私密提示、快捷卡三连）
2. 生长记录（一图秀 rail 双栏 + 指标卡 + 最近测量表）
3. 筛查台账（年度筛查项分组、结果记录、随访节律清单）
4. 事件档案（手术 / 用药折叠卡，details.phase-fold）
5. 就诊准备（资料包 + 待问清单 + 导出）
6. 临床试验（保留：登记快照 + 候选线索；禁匹配指数与判读列）
7. 设置（工作区 / 文档解析 MinerU / 临床数据库 三 Tab）

## 三、状态与一致性规则（X 组）

- X1 孤儿页=0：每个 (view,sub) 被至少一条路径经过（M2 穷举脚本出计数）。
- X3 手工/AI/导入三通道同写事实层与更正链；AI 候选逐项核对，拒收零副作用。
- IP5 除红线实体（筛查频次建议）外，可写实体均有 AI 候选通道，候选逐项核对。
- IP6 每页显式编辑入口 ≤1；表单 ≤6 字段；数字输入用数字键盘。
- IP10/IP11 每个一级页至少一处「和 AI 讨论」，携带本页关键信息（无判定词）进输入框，不代发。
- Q14 顶栏固定顺序：资料目录→设置→大字→AI→版本→?；AI 面板右侧 35% 可拖 25–45%。

## 四、R3 特有交互（差异化硬要求）

- 双视角徽标：页头显示「家长代记」/「本人查看」；一期默认家长代记。
- 隐私更严：所有记录默认非私密，但儿童照片类/身份类字段录入表单默认勾选「仅本机」；导出带代记标记。
- 档案切换（A/B 合成档案）在顶栏可见处，切换后整页联动不串档。
