# CLINICAL-DATA · 临床数据与医学边界（小苗宝 GrowPal）

版本：v0.1（M0 骨架；M1 十主题全量+原件核验）· 指南只定内容边界，不转成自测或选治疗。

## 一、医学边界红线

1. 本台仅回顾与整理家长可取得的事实；不判读生长、不评风险、不推荐治疗。
2. 生长百分位对照阈值、筛查频次、干预指征一律【待核】，以医生安排为准。
3. 中国适应证与批准状态只认中国官方来源（NMPA 等）；夜间未核实时写待核。
4. 未取得原件的信息标「据二次来源」。
